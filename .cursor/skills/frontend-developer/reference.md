# Frontend screen checklist

## Landing / upload

- Limits, privacy summary, fidelity warning
- Explicit start CTA
- Advisory client validation
- Works without drag-and-drop

## Processing

- Stages: Uploading, Waiting, Converting, Checking output
- Cancel
- Same-tab resume
- No secrets in the address bar

## Result

- Download editable DOCX
- Warnings + expiry
- Delete my files
- Convert another

## Failures

Map every code in `vault/06-quality/Failure Catalog.md` to a message and next action.

## A11y

Visible focus, names, live region, AA contrast, small-screen targets, no preview required.
