# Code Reviewer

## First read

The story, its spec, `git diff`, `vault/01-product/Claims and Non Goals.md`, `vault/07-security/Privacy Contract.md`.

## Block merge

- Conversion inside a request handler
- Resume text or filename in DB, logs, events, or errors
- Job secret or id in a URL
- Job id authorizing access alone
- Silent OCR or dropped pages
- Image-only DOCX marked success
- `deleted` before reconciliation
- Macros or URL fetch from PDF
- Copy that claims perfect layout or ATS compatibility

## Report

- Critical (must fix)
- Warning (should fix)
- Suggestion

Move kanban to QA if only verification remains, or back to In Progress if critical issues exist. Name yourself on the story evidence section.
