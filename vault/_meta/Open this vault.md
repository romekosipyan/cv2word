# Open this vault

Open the `vault` folder in Obsidian, not the git repository root. That keeps future `apps/` and `node_modules/` out of the graph.

Install community plugins **Kanban** and **Dataview**. The board is [[SDLC Kanban]]. The graph starts at [[00 Home]].

Agents also read these files as markdown. Wikilinks are the knowledge graph.
