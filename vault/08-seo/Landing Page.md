# Landing page

The primary landing page owns conversion intent. Spec: [[SPEC-SEO]]. UI: [[SPEC-UI]].

## Required blocks

1. Descriptive title and one H1.
2. Working upload tool above the fold.
3. Supported files, limits, and the fidelity warning.
4. Privacy summary with link to lifecycle details.
5. Synthetic before/after example.
6. How to edit the result in Word.
7. Internal links to [[Content Plan]] pages.

Use "CV" naturally on this same page. Do not create a competing near-duplicate CV landing page in P0.

## Out of page

Upload, status, and result URLs are not landing pages. They are noindex and absent from the sitemap.
