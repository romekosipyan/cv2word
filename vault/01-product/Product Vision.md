# Product Vision

Make a resume usable again within minutes: upload a PDF, receive an editable DOCX, review the result, and update it in a familiar editor.

The differentiator is resume-specific guidance, honest fidelity expectations, and a low-friction workflow. Generic converters may rearrange columns, split text, or lose bullets and links. ResumeToWord tells the user what to check before sending the file to an employer.

## Primary flow

Search result → [[Landing Page]] → choose or drop one PDF → validate → explicitly start conversion → upload and queue → process → quality check → download DOCX → review locally → delete files or allow automatic expiry.

Primary action label: **Convert resume to Word**.

## Differentiator constraints

Honesty is the product. Do not compete on "perfect layout" or "ATS guaranteed." Compete on tested resume usability and truthful privacy. See [[Claims and Non Goals]].
